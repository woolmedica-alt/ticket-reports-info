Privacy policy

Effective October 12, 2026. This policy describes the personal Ticket availability reports application.

Google access and use

The app requests Google Docs and Drive access to read and update the owner's selected ticket calendars and existing CSV. These authorization scopes permit broader document and file access, but the reporting script is configured to operate only on those selected files. Gmail permission is limited to sending reports; the app does not request permission to read the inbox.

Storage and service providers

The Google authorization token is stored in an encrypted GitHub Actions repository secret. The owner retains a private local authorization copy. Scheduled processing runs on GitHub Actions. Ticket snapshots, report message identifiers and timestamps are retained in the private repository to compare results and avoid duplicate emails. Scrape artifacts are configured to expire after seven days. Google stores the calendar documents and delivers email reports.

Sharing

Reports are sent only to the configured owner. The app does not sell Google user data, use it for advertising, or use it to train AI models. Google and GitHub process information as needed to provide their services. Repository collaborators with appropriate access can use the configured secrets in workflows.

Control and deletion

The owner can stop scheduled checks in GitHub Actions, revoke app access in Google Account settings, delete the repository secret and local authorization files, and delete stored snapshots, artifacts and reports. Revoking authorization stops subsequent Google updates. This information website does not collect visitor information through forms or app analytics; the hosting provider may maintain normal service logs.
